readme_content = """# LumaWatch 🌙

LumaWatch is an ultra-lightweight, intelligent adaptive monitor brightness engine built in Python. By dynamically sampling your screen's content and sending native commands directly to your monitor's hardware, LumaWatch provides smooth, automated brightness adjustments with zero background overhead.

---

## ✨ Features

* **Real-Time Screen Sampling:** Uses hyper-efficient matrix analysis to capture on-screen luminance values instantly.
* **Native Hardware Control:** Communicates directly with external and internal monitors via native DDC/CI protocols.
* **Modern DPI Scaling:** Fully optimized for Windows 10/11 high-DPI displays—ensuring text and UI indicators remain crisp and legible.
* **Low System Footprint:** Optimized processing loop loops safely in the background without stealing cycles from games or heavy applications.
* **Minimalist UI:** Simple, fluid control wheel panel to dial in your custom sensitivity curves.
